# My Dotfiles

They're basic but they're mine.

## Goal

This provides all the major things I use on the computer for easy portability when installing a new system. All files are symlinked with the Makefile to keep everything in sync across computers.

## Bin

- homebrewlogclean.sh: Cleans homebrew logs first Monday
- homebrewupdate.sh: Updates homebrew every Monday
- ipic: Search iTunes for media covers
- waybackup: Save to Archive.org

## Launchd

Launch Agents for homebrew updates

## Ghostty 

Config is symlinked to Application Support, so does not have Linux support.

## Zsh

Cached to speed up performance and doesn't freak out if programs aren't installed.
